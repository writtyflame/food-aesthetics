# AI食物美学评测 — 测评维度设计

## 一、六大测评维度

| 维度 | 说明 | 分值范围 |
|------|------|---------|
| 色彩和谐度 | 食材颜色搭配是否协调，有食欲的色彩组合 | 1-10 |
| 构图美感 | 菜品在画面中的构图，是否有美学意识 | 1-10 |
| 质感对比 | 食材之间质感差异（脆/软/糯/滑等）呈现程度 | 1-10 |
| 食欲指数 | 第一眼看下去是否让人产生想吃欲望 | 1-10 |
| 餐桌故事感 | 这道菜传递了什么氛围和情绪 | 定性描述 |
| 整体评分 | 综合加权得分 | 1-100 |

## 二、人格标签体系

根据测评结果，赋予一个"餐桌人格"标签：

| 标签 | 风格关键词 | 描述方向 |
|------|-----------|---------|
| 暖心治愈派 | 家常·温暖·幸福感 | 让人想起妈妈的味道 |
| 精致主义派 | 优雅·仪式感·审美 | 吃饭是一件艺术品 |
| 烟火街头派 | 接地气·热情·满足 | 市井味道最抚人心 |
| 自然本味派 | 健康·清淡·本真 | 食材自己会说话 |
| 冒险玩味派 | 新奇·创意·有趣 | 餐桌上的探险家 |
| 氛围营造派 | 浪漫·情调·仪式感 | 吃的是气氛 |
| 佛系干饭派 | 随性·真实·自在 | 饿了就吃，好吃就光盘 |

## 三、分享海报设计

- 竖版卡片样式（9:16比例）
- 顶部：菜品照片（圆角裁剪）
- 中部：人格标签 + 大字评分
- 底部：六个维度雷达图式展示
- 右下角：小程序码 / 品牌水印
- 配色：暖色调（琥珀色/米白/深绿）

## 四、技术选型

- 前端：纯 HTML/CSS/JS，PWA友好
- 后端：Cloudflare Worker（Python / JavaScript）
- AI：阿里云通义千问 VL 多模态模型（qwen-vl-max）
- 图片处理：前端 base64 压缩后传输
